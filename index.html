What it catches

Three things that go wrong most often when beginners run code they didn't write.

Hidden crypto miners

A program quietly using your processor for hours is a classic sign. Trust Run flags it and lets you stop it.

Stolen passwords and keys

Warns when something other than your browser opens your saved passwords or cookies, or touches secret files like .env and SSH keys.

Unfamiliar servers

Warns when a script connects to a server you wouldn't expect, the way programs that upload your files do.

Questions

Does it replace antivirus?

No. Trust Run is a watcher for programs you run yourself, especially scripts from AI tools and the web. It is not a full antivirus suite, and it is not a guarantee. It warns you so you can decide.

Will it slow down my Mac?

It checks quietly every few seconds and uses very little power.

What if it warns about something that is fine?

Click "Always trust" on the warning and it will not bring up that exact program doing that exact thing again.

Which computers does it work on?

Macs today. A Windows version is planned once the Mac version is finished.
